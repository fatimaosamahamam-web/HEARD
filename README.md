# HEARD 💗

### You Will Always Be Heard.

HEARD is a women's health app concept designed to make women's healthcare experiences more supportive, accessible, and empowering.

## About HEARD

HEARD was designed around one simple belief: every woman deserves to be heard, understood, and taken seriously when it comes to her health.

The project combines app development and user interface design to bring this idea to life.
